# Prompt de la prueba

No escribas código ni adivines datos. Responde solo con lo que puedas leer del repositorio y los archivos disponibles en esta conversación. Si no puedes acceder a una ruta o leerla completa, indica «NO ACCESIBLE» o «LECTURA INCOMPLETA».

**Fase A — acceso a repo:** abre `https://github.com/Pololo06/AutoUML-v3` y responde con: rama y número de commits visibles; última línea literal de `GEMINI.md`; última línea literal de `docs/plan-1.md`; número de líneas y última línea literal de `tests/fixtures/puml/real-66.puml`; primer y último nombre alfabético de `tests/fixtures/golden/`. No completes datos por inferencia.

**Fase B — tamaño:** para cada archivo de muestra adjunto, informa nombre, tamaño en bytes (si está disponible), marcador BEGIN literal y marcador END literal. No reproduzcas el contenido intermedio. Si hay varios, reporta cada uno.

**Fase C — cantidad:** para los archivos `count-40/file-NN.txt` disponibles, enumera en orden las marcas BEGIN y END de cada archivo. No omitas ninguno; indica si la lista parece incompleta.
